# Tasks

Tasks is one shared work list across the environments connected to T3 Code. Open it with the third
button in the **Threads / Agent Chats / Tasks** switch. Checklist and Kanban are two views of the same
durable list, so completing or moving a card updates every connected client.

Each task has a title, optional notes and due date, and one of four states: Backlog, Todo, In
Progress, or Done. A task can also link to a project or thread in its own environment. Deleting that
project or thread keeps the task and clears only the link.

On desktop, drag cards between Kanban columns or use the checklist to complete them. The compact
Tasks card above provider usage shows the nearest due unfinished task. Open the card to see the five
nearest items, ordered with overdue tasks first.

On iPhone and iPad, switch to Tasks from Home. Long-press a task to choose its state. VoiceOver users
can move a task forward or backward, toggle completion, or delete it through the task's accessibility
actions.

Agent Chats can manage Tasks only after **Allow task management** is enabled in that Agent Chat's
settings. The permission is off by default and is separate from routine management and browser
access.
