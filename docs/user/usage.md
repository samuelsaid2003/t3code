# Review usage

The Usage page combines Codex and Claude Code activity from your connected environments. It reads
the providers' local session history and shows API-equivalent token cost, processed tokens, cache
savings, provider shares, and model breakdowns. Subscription billing is separate from the raw token
cost shown here.

On desktop and web, the thread sidebar can also show **Codex Usage: N%**. That number is the
ChatGPT subscription window percent Codex reports (`usedPercent`), not a cost calculated from
token history. It appears once Codex has been checked and an authenticated subscription window is
available.

Use **Past 24h** for an hourly chart covering the exact rolling 24-hour period. The **7 days**,
**30 days**, and **90 days** ranges use daily resolution. Cost and token toggles update both the
headline and chart, and refreshing rescans every connected environment.
